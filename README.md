# 📊 Article Analyzer

A Python bot that analyzes articles and gives feedback.

## ✨ Features
- Counts words and sentences
- Finds the most frequent keywords
- Filters out stop words (like "the", "is", "and")
- Shows top 10 most important words

## 🚀 How to Run
1. Run `analyzer.py` with Python 3
2. Paste your article text
3. Press Enter twice to finish
4. See the analysis report!

## 🛠️ Built With
- Python 3
